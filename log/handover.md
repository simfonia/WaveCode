# WaveCode 開發交接與進度

## 2026-03-08 ~ 2026-04-08 (略)

## 2026-04-09 (演奏積木移植、多軌隔離與搜尋引擎升級)

### 1. 本次對話達成
- **演奏系統完備 (Performance Blocks)**：
    - 完整移植了支援拍數 (Beats)、力度 (Velocity) 與時值代碼 (W, H, Q, E, S) 的演奏積木。
    - 實作了多軌並行 (Multi-tracking) 隔離：每個音軌具備獨立的 `_playbackTime` 計時器，且 `Voice` 會深拷貝 Patch 物件，杜絕數據踩踏。
- **音量基準標準化**：
    - 解決了音量微弱的 Bug：統一由 `factory.js` 處理百分比轉換，Compiler 不再預先除以 100。
    - 清理了過度增益補償，音訊引擎現在以高品質 1.0 Gain 為基礎運作。
- **搜尋引擎 2.0 (Search Refinement)**：
    - 支援中文搜尋：改為實體積木索引機制，能精確抓取翻譯後的標籤文字。
    - 支援影子積木：搜尋結果現在包含原始 Toolbox 定義，帶有正確的預設值。
    - UI 升級：搜尋框圓角化、桃紅邊框發光樣式、圖示垂直置中修正。
- **穩定性修復**：
    - 修正了開檔即變成 Dirty 的時序 Bug。
    - 更新了 `melody_zh-hant.html` 說明文件。

### 2. 技術細節
- **軌道隔離機制**：在 `api.js` 中所有 Async 方法必須引用 `this`。當 `wc_perform` 被觸發時，透過 `Object.create(WaveCodeAPI)` 產生具有獨立 `_playbackTime` 的實例。
- **搜尋快取策略**：`BlockSearcher` 會遍歷 JSON 版 Toolbox，將 `contents` 拍扁後快取為 `_rawDefs` Map，供 `flyout.show()` 直接使用。

### 3. 下一步行動
- **錄音功能**：實作 `MediaRecorder` 或 `OfflineAudioContext` 以支援錄製演奏並匯出 WAV 檔。
- **文檔補完**：撰寫 `effects` 與 `master` 的輔助說明 HTML。
