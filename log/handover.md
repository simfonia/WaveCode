## 2026-04-18 (積木資產自動化、工作區全量匯出與視覺精確化)

### 1. 本次對話達成
- **積木資產匯出系統 (Block Exporter)**：
    - **[自動化工具]**：實作 `dev_tools.js`，支援批次匯出所有積木為 SVG/PNG。具備自動分類功能（Toolbox / Mutators / Residuals）並整合 ZIP 打包下載。
    - **[UI 整合]**：新增左下角紫色懸浮按鈕（Download FAB），具備實時百分比進度與 `LogManager` 聯動報表。
- **專案全量匯出 (Workspace Export)**：
    - **[右鍵選單功能]**：在工作區空白處新增「匯出 SVG」與「匯出 PNG (高品質)」選單。
    - **[座標與偏移修正]**：解決積木被截斷問題。技術核心為移除克隆層的 `transform` 殘留，並改用工作區 Surface 座標重新計算 ViewBox。
    - **[高品質渲染]**：PNG 支援 2x 解析度縮放，並自動填補 `#050505` 背景底色，達成「所見即所得」的精確排版。
- **視覺狀態修復**：
    - **[停用積木強化]**：利用 CSS 暴力選擇器與 `!important` 覆寫 SVG 內聯屬性，修復了停用積木（Disabled）在深色背景下不可見的 Bug。
    - **[字體統一]**：將匯出字體大小鎖定為 `11pt`，解決排版溢出問題。
- **架構規畫**：正式加入 **WaveCode Web 版 (GitHub Pages)** 計畫。

### 2. 下一步行動
- **說明文件內容填充**：利用自動化生成的資產包開始整理積木 HTML 說明。
- **Web 環境適配測試**：測試資源 HTTP 載入路徑對 Web Audio API 啟動延遲的影響。
