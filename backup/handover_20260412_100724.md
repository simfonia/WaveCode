# WaveCode 開發交接與進度

## 2026-03-08 ~ 2026-04-09 (略)

## 2026-04-11 (精密排程革命、萬用音序器與 MDI 穩定化)

### 1. 本次對話達成
- **精密排程與對位系統 (Precision Scheduling)**：
    - **Look-ahead (150ms)**：JS 邏輯領先音訊時鐘排程，徹底解決多軌漂移與「快速播完」Bug。
    - **瞬時排程序列器**：`playRhythmV2` 改為非阻塞瞬時緩衝模式，解決並行軌道間的計時競爭。
    - **上下文時間繼承**：`createTrack` 現在會繼承 Parent 進度，確保預備拍與背景音軌精確銜接。
- **演奏系統升級**：
    - **萬用解析器**：支援音名、和弦、連音符 (-)，解析邏輯對齊 HarmoNyx。
    - **全拍號支援**：序列器與預備拍皆支援自定義分母 (Beat Unit)，支援 3/4, 6/8 拍。
    - **力度後綴語法**：旋律譜支援 `C4Q:120` 緊湊寫法。
- **UI/UX 與效能優化**：
    - **全域剪貼簿**：實作跨分頁 Ctrl+C/V 積木複製功能。
    - **渲染節流**：示波器降至 30fps，大幅釋放 CPU 給 Blockly 渲染，平移大型工作區不再卡頓。
    - **自動邊距對齊**：開啟範例後自動保留 30px 間距。
- **核心架構穩定化**：
    - 回歸單一 `api.js` 架構，排除模組拆分導致的作用域遺失。
    - 修復了 Sampler 節點鏈 Bypass Bug，確保 Volume 積木百分之百生效。

### 2. 技術細節
- **時鐘同步機制**：在 `waitMusical` 加入 `if (this._playbackTime < now - 0.2) this._playbackTime = now;` 容差校正，防止 JS 執行緒在系統負載過高時陷入趕工死循環。
- **解析器緩衝掃描**：使用 HarmoNyx 风格的字元緩衝掃描，正確識別變長標記（如 `Eb4`）並精確對位到物理步進。

### 3. 下一步行動
- **錄音與 WAV 匯出**：實作 `MediaStreamAudioDestinationNode` 將全域 Master 訊號串流至 `MediaRecorder` 並匯出。
- **Reverb 效果器**：研究並實作卷積殘響 (Convolution Reverb) 或 Freeverb 算法。
