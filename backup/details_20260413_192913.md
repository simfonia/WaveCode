## 2026-04-13 (樣板載入機制、IDE 事件優先級與多採樣算法)

### 1. 樣板載入的異步競爭處理
- **問題**：在 `MDIManager` 中立即載入 XML 會因 Blockly 尚未完全繪製 SVG 而導致坐標偏移。
- **解決方案**：使用 `setTimeout(async () => { ... }, 50)` 包裹載入邏輯。載入後額外執行 `workspace.scrollX += 30; workspace.scrollY += 30;` 補償邊距。

### 2. 鍵盤事件攔截的優先級優化
- **競爭點**：`KeyboardController` 在 `window` 上監聽 `keydown` 並執行 `stopImmediatePropagation()`。
- **修復方案**：將 `Escape` 判定移至 `isTyping()` 之後。在 `ui_utils.js` 中使用 `capture` 模式攔截 Esc，確保搜尋框能優先清除內容。

### 3. 多採樣映射 (Multi-sampling) 算法優化
- **算法核心**：`findBestSample(sampleMap, prefix, targetFreq)`。
- **匹配規則**：
    - 強制檢查 ID 是否以 `prefix_` 或 `prefix-` 開頭 (不分大小寫)，避免如 `bass` 誤中 `double_bass` 的情況。
    - **下移懲罰 (Pitch Down Penalty)**：在計算音高距離時，若目標音高低於取樣音高（需要降調播放），距離加權 3.0 倍。這會讓引擎傾向選擇低音區的取樣並「升調」播放，因為升調比降調更能保留高頻細節，聽感更明亮且自然。
- **Fallback 機制**：`NodeFactory` 會優先嘗試精確 ID 匹配，失敗後才啟動前綴模糊匹配，兼顧了單發打擊樂與多採樣樂器的需求。
