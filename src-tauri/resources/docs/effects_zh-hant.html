音訊效果器 (Audio Effects)

效果器是音訊合成的「鍊金術」。它們透過數學運算與物理模擬，改變原始振盪器產生的波形。在 WaveCode 中，效果器遵循串行連接 (Series Connection) 原則：訊號會從上至下流經每個積木，前一個效果器的輸出即為下一個的輸入。

順序的重要性： 不同的排列會產生截然不同的音色。例如：失真 -> 濾波 會產生溫暖的電子音色；而 濾波 -> 失真 則會讓失真效果作用於特定頻段，產生更具侵略性的聲音。

1. 濾波器 (Filter)

濾波器透過移除或增強特定頻譜範圍來修飾音色。這是合成器中最核心的塑音工具。

物理原理： 濾波器本質上是「頻率依賴性增益器」。低通濾波器透過電路中的電容特性阻礙高頻電流，物理上模擬了聲音在穿過牆壁或水面時，高頻能量被吸收現象。Q 值則是在截止頻率點產生的「正回饋」，會導致特定頻率的能量疊加，產生尖銳的共振。
  • 類型 (Type)：
    • 低通 (Low Pass)：濾除截止頻率以上的聲音。適合模擬「悶音」或「溫暖」的質感。
    • 高通 (High Pass)：濾除截止頻率以下的聲音。適合移除低頻噪音或製作尖銳、薄弱的音色。
    • 帶通 (Band Pass)：僅保留截止頻率附近的聲音。
  • 頻率 (Frequency) [20 - 20000 Hz]：設定「切斷點」。人耳聽覺範圍約為 20Hz 至 20kHz。
  • Q 值 (Quality Factor) [0.1 - 10.0]：共振強度。高 Q 值會在切斷點產生一個突出的波峰，讓聲音聽起來帶有「哨音」感。

2. 延遲 (Delay)

將訊號儲存在暫存器中並延後一段時間輸出，模擬聲音在空間中反射產生的回聲。

物理原理： 聲音在空氣中傳播速度約為 340m/s。延遲效果器模擬了牆面反射。當回饋量 (Feedback) 很高時，訊號會不斷重複進入延遲鏈，如果延遲時間極短（低於 20ms），會產生梳狀濾波 (Comb Filtering)，導致特定頻率因相位抵消而消失。
  • 延遲時間 (Time) [0.01 - 5.0 秒]：原始音與反射音之間的時間差。
  • 回饋量 (Feedback) [0.0 - 0.95]：反射音再次進入延遲鏈的比例。0 代表只重複一次；0.9 代表會產生長久不散的回聲鏈。

3. 位元粉碎 (BitCrush)

一種數位失真技術，透過降低數位音訊的精確度來產生粗糙、懷舊的 8-bit 風格音色。

物理原理： 數位音訊利用「位元深度」來決定動態範圍。量化誤差 (Quantization Error) 是當位元不足時，平滑的波形被迫變成「階梯狀」的過程。這會產生大量的奇數諧波，聽起來像是數位化的雜音。
  • 位元深度 (Bits) [1 - 16]：數值越小，聲音越粗糙。1-bit 代表只有「開/關」，會產生極其劇烈的雜音；8-bit 是典型的復古遊戲機質感。

4. 失真 (Distortion / Waveshaper)

模擬類比電路因超載而產生的波形「削頂」現象，賦予聲音攻擊性與厚實感。

物理原理： 透過非線性函數（如 Sigmoid）將波形的峰值壓平。這種波形變形在頻譜上表現為諧波增加 (Harmonic Generation)。正弦波經過失真後會接近方波，從而獲得豐富的高頻泛音。
  • 失真程度 (Amount) [1 - 100]：數值越大，波形被壓縮與削平得越嚴重，聲音越「炸」。

5. 壓縮器 (Compressor)

壓縮器是自動音量管理員。它會縮小訊號的「動態範圍」（最大聲與最小聲的差距），讓聲音更紮實、一致。

物理原理： 壓縮器透過偵測輸入能量，當超過閾值時，依據比率調低增益。啟動時間決定了聲音的「瞬態 (Transient)」是否被保留。壓縮後聲音通常會變小，因此需要補償增益來拉回總體音量。
  • 閾值 (Threshold) [-60 - 0 dB]：超過此分貝值時，壓縮器開始工作。
  • 壓縮比率 (Ratio) [1 - 20]：例如 4 代表每超過閾值 4dB，輸出僅增加 1dB。
  • 啟動時間 (Attack) [0.001 - 0.5s]：壓縮器反應的速度。極短的 Attack 會消滅鼓點的打擊感。
  • 釋放時間 (Release) [0.01 - 2.0s]：音量恢復正常的速度。
  • 補償增益 (Makeup Gain) [0 - 20 dB]：壓縮後將整體音量補回，使聲音聽起來更宏亮且細節清晰。
混合建議： 使用「壓縮器」放在訊號鏈末端（音量積木之前），可以有效防止多個效果器疊加導致的 Clipping，並讓您的合成器音色在混音中更具存在感。
