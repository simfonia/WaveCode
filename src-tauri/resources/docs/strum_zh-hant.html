🎸 吉他刷弦 (Struming)

吉他刷弦系統模擬了真實吉他的物理演奏特性。它不是簡單地同時播放 6 個音，而是根據撥弦方向產生微小的時間位移（Strum Offset），讓每一根弦依序響起。

積木說明

[和弦]：選擇要彈奏的和弦（如 C, G, Am）。系統會自動映射到吉他 6 弦的正確 MIDI 音高。
[節奏代碼]：輸入節奏型（預設為 16 分音符為一格）。
[力度]：基本彈奏力道 (0-127)。
[± 浮動音量]：每一刷隨機增減的力度範圍，增加人性化感。
[樂器名稱]：選擇發聲樂器。

🎼 支援的和弦符號 (Preset Chords)

您可以在積木的第一個欄位直接輸入以下符號。系統支援 # 或 b 的自動移調（例如輸入 C# 會自動將 C 的指法整體上移一格）。

C / CM7 / C7 / Cm
D / DM7 / D7 / Dm / Dm7
E / EM7 / E7 / Em / Em7
F / FM7 / F7 / Fm
G / GM7 / G7 / Gm
A / AM7 / A7 / Am / Am7
B / B7 / Bm / Bm7

U全弦上挑反向掃過所有弦 (Upstroke)。

u高音上挑僅刷動第 1-4 弦。

🎨 建議參數設定 (Guitar Patch Settings)

要在合成器中模擬好聽的吉他，關鍵在於 Attack (攻擊時值) 必須極短以模擬撥片撞擊聲。以下是針對不同風格的專業建議：

1. 民謠吉他風格 (Acoustic Guitar Style)

模擬鋼弦吉他的清脆感，最適合用於配合 wc_strum 進行掃弦演奏。

  • 波形 (Oscillator)：Triangle (較溫潤) 或 Square (較清脆)。
  • ADSR 設定：
    • Attack (A): 0.005 - 極短，模擬撥片接觸琴弦的瞬間。
    • Decay (D): 0.8 - 模擬撥弦後聲音自然變小的過程。
    • Sustain (S): 0.1 - 保持一個很低的持續音。
    • Release (R): 0.6 - 放手後餘韻自然消失。
  • 低通濾波器 (LPF)：頻率 2500 Hz (濾除刺耳電音) / Q 值 1.2 (微提亮撥弦特徵)。
  • 效果器：加上 Reverb (殘響)，Mix 設為 20%，增加空間共鳴。

2. 電吉他破音風格 (Overdrive / Rock Style)

適合搖滾節奏或強力的 D-U- 刷弦。

  • 波形 (Oscillator)：Sawtooth (諧波最豐富)。
  • ADSR 設定：
    • Attack (A): 0.01 / Decay (D): 0.5
    • Sustain (S): 0.4 - 因為破音會壓縮動態，持續音可以設高一點。
    • Release (R): 0.3
  • 失真 (Distortion)：Drive 設為 40 ~ 70。
  • 低通濾波器 (LPF)：頻率 3500 Hz (避免鋸齒波過於刺耳)。
💡 進階技巧：如何讓刷弦更像真的？

1. 使用壓縮器 (Compressor)：
在 wc_master 或樂器鏈後面加上壓縮器（Thresh: -24, Ratio: 4），可以讓掃過 6 根弦時的音量更均勻，防止多音並發時音量突然暴增。

2. 善用 Pattern 空格：
不要將代碼填得太滿。例如 D-.. U-.. 留下的延音 - 會讓吉他的物理共鳴感更好。

3. 力度變化 (Velocity Randomization)：
在積木的「± 浮動音量」處設定數值（推薦 10-20），模擬人類彈奏時微小的力度不穩定，會讓機器人演奏更有靈魂。
