MIDI 與 Launchpad 控制

WaveCode 支援標準 Web MIDI 通訊，讓您可以輕鬆實現硬體與程式的即時互動。系統會自動掃描並監聽所有連接的 MIDI 裝置。

1. 接收訊號 (Input)

當收到 MIDI 音符 ON / OFF

當您按下 MIDI 鍵盤上的按鍵時會觸發。變數會儲存 ch (頻道)、note (鍵號) 與 vel (力度)。

進階演奏： 您可以在「按下」時觸發音長為 0 的持續音，並在「放開」時呼叫「釋放音符」積木，實現手動控制音長的手感。

當收到 MIDI CC 控制訊號

用於監聽旋鈕或推桿。系統會將數據存入 ch (頻道)、number (編號) 與 value (數值)。適合即時調整音量或效果。

2. Launchpad 專用工具

Launchpad 座標轉換

此工具將 8x8 網格座標 (X, Y) 轉換為 MIDI 音符編號。請依據您的硬體型號選擇模式：

經典 (XY) 模式

公式：Y * 16 + X

適用硬體：
Launchpad S / Classic / Mini / Mini MK2。

現代 (Note) 模式

公式：11 + X + (Y * 10)

適用硬體：
Launchpad MK2 / X / Pro / Mini MK3。

  • 網格範圍均為 X (0-7), Y (0-7)。
提示： 若要開始使用 MIDI，請確保裝置已連接，並在啟動專案後點擊一次頁面任意處以啟用瀏覽器的存取權限。
