旋律與節奏編寫指南

WaveCode 使用音樂性的單位（拍數與力度）來取代傳統的毫秒，讓程式設計更貼近音樂創作。本指南適用於所有「演奏」分類下的積木。

1. 音符與和弦 (Notes & Chords)

在「音符」欄位中，你可以輸入以下內容：

  • 單音：包含音名 (A-G)、記號與八度 (0-9)。
    • 升記號：支援 #, s, S。例如 C#4 或 Cs4。
    • 降記號：支援 b, B。例如 Eb4 或 EB4 (Bb 亦可正確識別)。
  • 休止符：使用 R 代表不發聲。
  • 和弦名稱：若你已使用「定義和弦」積木，可直接輸入名稱如 MyChord。
  • 頻率：直接輸入數字如 440 (Hz)。

2. 持續時間與時值代碼 (Duration)

持續時間以「拍 (Beats)」為單位。你可以輸入數字，或使用以下代碼：

代碼名稱拍數 (以 4/4 拍為例)
W全音符 (Whole)4 拍
H二分音符 (Half)2 拍
Q四分音符 (Quarter)1 拍
E八分音符 (Eighth)0.5 拍
S十六分音符 (Sixteenth)0.25 拍

進階修飾符：

  • 附點 .：增加 50% 長度。例如 Q. 代表 1.5 拍。
  • 三連音 _T：縮短為 2/3 長度。例如 Q_T。
  • 連結線 +：累加多個時值。例如 H+Q 代表 3 拍。

3. 演奏力度 (Velocity / Articulation)

力度範圍為 0 到 100+。在「演奏旋律清單」積木中，您可以使用後綴來精確控制個別音符的力度：

  • 語法：音名+時值:力度 或 音名+時值v力度
  • 範例：C4Q:120 (重音)、E4Qv60 (弱音)

力度會影響：

  • ADSR 峰值：力度越高，Attack 頂點越響亮。
  • 取樣器音量：與樂器定義中的音量積木進行乘算。
💡 專業小技巧：
「演奏旋律清單」積木中，每一個音符事件內部不可包含空白。請將音名、時值與力度緊連在一起（如 C4Q:120），並使用空格或逗號來區隔不同的音符。

4. 語法範例

// 基本四分音符 (音名與時值連寫) C4Q // 帶有力度的八分音符 G3E:80 // 複雜的旋律清單語法 (playMelody) C4Q E4Q G4H R Q C5W // C大三和弦分解音 -> 休止 -> 高音C全音符

5. 多軌並行 (Multi-tracking)

當你在多個「演奏帽子積木」中編寫代碼時，WaveCode 會為每個帽子積木建立獨立的「音軌」。每個音軌擁有獨立的計時器，彼此互不干擾，這讓你可以輕鬆實現複雜的合奏。
