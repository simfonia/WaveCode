Melodic Sample Set (Folder)

Used to play instruments with pitch variations (e.g., Piano, Strings, Flute). The system automatically maps multiple pitch samples to their correct positions.

How to Use

  1. Folder Menu: Select the directory containing the melodic samples.
  2. Auto-Mapping: If the folder contains files named with note tags like C4, D4, the system will enable auto-mapping.

Folder Structure & Naming

Sample sets should be placed in src-tauri/resources/samples/[Folder_Name]/. Recommended naming:

samples/
└── piano/
    ├── C4.wav
    ├── Cs4.wav (C#4)
    └── G4.wav

Smart Pitch Compensation

  • Nearest Matching: When playing D4, if only a C4 sample exists, the system picks C4 and shifts its pitch up.
  • Quality Preservation: The engine prefers picking a lower sample and shifting it up to maintain the brightness and detail of the sound.
💡 Detection Logic:
If your folder does not contain any files matching the [Note][Octave] format, it will not appear in this menu. Use the Percussion Sampler instead.
