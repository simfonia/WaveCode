Percussion Sampler

Used to play single hits or percussion sounds (e.g., Kick, Snare, Clap). These sounds usually do not require pitch shifting.

How to Use

  1. Folder Menu: Select the directory containing your percussion sounds.
  2. File Menu: Select the specific sound file within that directory.

Custom Samples

You can add your own .wav or .mp3 files to the following path:

src-tauri/resources/samples/[YourFolder]/[YourSound.wav]

Restart the application, and your folders/files will automatically appear in the menus.

💡 Smart Filtering:
The system automatically filters out "Melodic" folders. If a folder contains pitch samples like C4 or D4, please use the "Melodic Sample Set" block instead.
